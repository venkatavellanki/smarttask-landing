# SmartTask | Productivity App Landing Page

## Overview
Hi! I’m **Venkat Vellanki**, and this is a landing page I built for **SmartTask**, a productivity app designed to help users organize tasks, track progress, and boost productivity.

I designed this landing page to be:
- Visually appealing with a modern, professional look  
- Fully responsive for desktop and mobile devices  
- Easy to navigate with smooth scrolling and clear sections  
- Certification-ready, demonstrating my front-end development skills

---

## Features

The landing page includes the following sections:

1. **Home / Hero** – Introduces the app and provides a clear call-to-action  
2. **Features** – Highlights core functionalities like task management, smart reminders, and analytics  
3. **How It Works** – Step-by-step guide for users to get started  
4. **Pricing** – Displays Free and Pro plans  
5. **Testimonials** – User feedback for credibility  
6. **Download** – App download call-to-action  
7. **Contact** – Provides email and phone for inquiries  

Additional features:
- Interactive Navbar with smooth scrolling  
- Hover effects on feature and pricing cards  
- Gradient backgrounds and visually engaging typography
